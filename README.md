# Pomelo

A native macOS app that spins up a full, isolated, runnable environment for
every branch — services, databases, and shared infra, wired automatically.
No YAML archaeology, no port juggling.

## Install

1. Download the latest **`Pomelo-<version>.dmg`** from the
   [Releases](https://github.com/toantran292/pomelo-releases/releases/latest).
2. Open it and drag **Pomelo** into **Applications**.
3. Launch Pomelo and point it at the folder that holds your repos.

Requires macOS 14 (Sonoma) or later, Apple Silicon or Intel. Signed with an
Apple Developer ID and notarized, so it opens without Gatekeeper warnings.
